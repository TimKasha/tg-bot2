# 🤖 «Собутыльник MAX» — бесплатный облачный бот-собеседник для Telegram

Бот, который живёт 24/7 в облаке, разговаривает в личке и в беседах, настраивается под твой тон —
вплоть до **собственного мини-приложения с настройками** внутри Telegram. Стек полностью бесплатный.

## Что умеет (всё уже включено)

- 💬 Разговор в личке и беседах (различает участников по именам, помнит контекст до 14 сообщений)
- 🎭 **Тон под себя**: `/tone` (Дружелюбный / Саркастичный / Гопник / Мудрец / Ночной) или `/persona` — характер своими словами
- 🏷 **Имя**: бот по умолчанию «Олег» и отзывается на имя в беседах; поменять — `/name` (также в Mini App)
- 📱 **Mini App**: `/settings` → кнопка «Открыть приложение настроек» — все настройки с кнопками прямо в Telegram
- 🗣 Режимы в беседах: `/mode` — по обращению / на всё / молчать + триггер-слова `/triggers`
- 🌙 **Вечерняя сводка каждый день (по умолчанию 22:00)**: о чём был день, самый активный, **самый смешной по реакциям 😂**, победители игр + небольшой квиз. Управление: `/daily on|off`, `/daily time HH:MM`, `/daily zone N` (часовой пояс), `/daily тест`
- 😂 Реакции считаются автоматически — поставь 😂 или 🤣 на смешное сообщение, и автор получит баллы
- 🕹 **Игры**: `/quiz` — викторина с кнопками, `/num` — угадай число, `/dice` — кубик, `/coin` — монетка, `/top` — короли чата (баллы: победа +2, реакция +1, 😂🤣 +2)
- 🎙 **Голос**: голосовое сообщение → расшифрую и отвечу текстом. `/voice текст` — озвучу текст голосом (бесплатный Edge TTS)
- 🖼 `/img описание` — нарисую картинку
- 📰 `/news тема` — свежие новости · 📺 `/yt <ссылка>` — пересказ YouTube-видео по субтитрам
- 🧠 **Память-досье**: `/remember факт` или просто напиши «запомни: …» — бот запомнит и учтёт в разговоре; `/memory`, `/forget`
- ⏰ Напоминания: `/remind 10м текст`, `/reminders`
- 🔔 `/digest` — пересказ последних сообщений беседы · `/ask` · `/joke` · `/say`
- 🛡 **Модерация**: антифлуд (авто-предупреждение и мут), стоп-слова `/stopwords` (авто-удаление), `/warn` (3/3 → мут 10 мин), `/mute 10`, `/unmute`, `/ban`/`/unban`, `/digest` для бесед
- 💾 Настройки и память — локально в SQLite, а лучше в общей базе Supabase (шаг 7): тогда переживают любые перезапуски

## Запуск за 5–10 минут

### 1–2. Telegram
1. **Токен**: @BotFather → `/newbot` → скопируй токен → `BOT_TOKEN`.
2. **Для бесед**: @BotFather → `/mybots` → твой бот → *Bot Settings* → *Group Privacy* → **Turn off**
   (иначе бот не увидит сообщения беседы: игры, сводку, антифлуд).

### 3. Бесплатный «мозг» (AI-ключ)
Самый простой — Google AI Studio: https://aistudio.google.com/apikey → Create API key → `AI_API_KEY`.
Если Google недоступен в твоём регионе — бери **Groq** (https://console.groq.com/keys):
он соответствует варианту 2 в `.env.example`, и бонусом расшифровывает голосовые через Whisper.
Или OpenRouter (free-модели). Всё меняется тремя строками в `.env` — детали в самом файле.

### 4. Локальная проверка (2 минуты)
```
cd tg-bot
скопируй .env.example → .env, заполни BOT_TOKEN и AI_API_KEY
py -m pip install -r requirements.txt
py bot.py
```
Напиши боту в Telegram — должно ожить.

### 5. Облако без карты — GitHub Actions (24/7)
Бесплатные PaaS в 2026 всё чаще пускают на карту (Render просит, Koyeb — $29 холд,
Docker-спейсы HF стали платными). Проверенный обходной путь — GitHub Actions:
публичный репозиторий даёт безлимитные минуты, воркер живёт до 6 часов и автоматически
перезапускается каждые 5 часов (в репозитории уже есть `.github/workflows/bot.yml`).

1. **Репозиторий**: github.com → New repository → имя `tg-bot` → **Public** (нужно для безлимита) → Create.
2. **Код**: в пустом репо — *uploading an existing file* → перетащи файлы проекта
   (`bot.py`, `storage.py`, `ai.py`, `webapp.py`, `app.html`, `requirements.txt`, `README.md`,
   `.env.example`, `supabase-schema.sql`, папку `webapp`, `.github/workflows/bot.yml`).
   `.env` НЕ загружай — ключи идут через Secrets.
3. **Секреты**: Settings → Secrets and variables → Actions → New repository secret:
   - `BOT_TOKEN` = твой токен
   - `AI_API_KEY` = твой AI-ключ
   (AI_BASE_URL/AI_MODEL уже стоят по умолчанию правильные; можешь добавить при смене провайдера.)
4. **Старт**: вкладка Actions → слева workflow `bot` → **Run workflow** → Confirm.
   В логе прогона через минуту увидишь `Бот @... запущен` — значит, бот уже отвечает в Telegram.
5. Дальше он живёт сам: каждые ~5 часов GitHub тихо пересобирает и перезапускает его
   (пауза ~1 минута). UptimeRobot не нужен — уснуть не может.

Нюансы Actions:
- Настройки/память в SQLite живут внутри прогона: после каждого ~5-часового перезапуска
  они сбрасываются — **если не подключена Supabase-база из шага 7**. С ней ничего не сбрасывается.
- Мини-приложение настроек с кнопкой — работает только после шага 7 (Vercel даёт постоянный https-адрес).
- Секреты в Actions шифруются и в логи не печатаются; виден только код (он и так открыт).

### 6. Для бесед
@BotFather → `/mybots` → твой бот → *Bot Settings* → *Group Privacy* → **Turn off**,
добавь бота в чат → `/daily тест`.

### 7. Mini App + несбрасываемые настройки — Vercel + Supabase (бесплатно, без карты)
Так бот в Actions получает постоянный https-адрес приложения и общую базу с ним:
**Supabase** хранит настройки/память/рейтинг (бот и приложение пишут в одну базу),
**Vercel** бесплатно хостит сам Mini App. Обе регистрации — без карты.

#### 7.1 Supabase (база, ~5 мин)
1. https://supabase.com → Sign up → **New project** (название любое, пароль запиши) → Create.
2. В проекте: левое меню **SQL Editor** → вставь туда весь файл `supabase-schema.sql`
   (лежит в проекте) → кнопка **RUN**. Снова запускать его можно безопасно.
3. **Settings → API**: скопируй
   - *Project URL* — это `SUPABASE_URL`;
   - ключ **service_role** (secret) — это `SUPABASE_SERVICE_KEY`.

#### 7.2 Vercel (приложение, ~5 мин)
1. https://vercel.com → Sign up (можно через GitHub-аккаунт).
2. Загрузи папку `webapp` (бывшая `upload-to-vercel`: `api/index.py` со строчкой импорта,
   `public/app.html`, `webapp.py`, `storage.py`, `requirements.txt`, `vercel.json`)
   в свой GitHub-репозиторий бота (в корне — так же, как остальные файлы).
3. Vercel → **Add New → Project** → импортируй репозиторий бота →
   в настройках импорта укажи **Root Directory = `webapp`** → Deploy.
4. Получишь адрес вида `https://имя-проекта.vercel.app` — это `PUBLIC_URL`.

#### 7.3 Соединяем
1. В **Vercel**: Project → Settings → Environment Variables → добавь:
   `BOT_TOKEN`, `SUPABASE_URL`, `SUPABASE_SERVICE_KEY` → Redeploy.
2. В **GitHub** (репозиторий бота): Secrets → добавь `SUPABASE_URL`,
   `SUPABASE_SERVICE_KEY` и `PUBLIC_URL` (адрес от Vercel) → **Run workflow**.
3. Готово. Теперь:
   - в `/settings` появилась кнопка «⚙️ Открыть приложение настроек»;
   - слева от поля ввода — меню-кнопка «⚙️ Настройки» (Mini App);
   - настройки/рейтинг/досье больше не сбрасываются при перезапусках;
   - старые данные из `bot.db` не переносятся — выстави характер один последний раз 🙂

## Про «без цензуры» — честно

- В коде бота **не запрешено ничего**: контент определяет только провайдер модели.
- Бесплатные облачные провайдеры (Google, Groq, OpenRouter) держат собственные фильтры — снять их нельзя,
  это их политика. Упёрся в фильтр — смени провайдера тремя строками в `.env` (у Groq/OpenRouter мягче).
- Ноль фильтров гарантирован только на своём backend (Ollama/LM Studio на своей машине), но тогда это не облако.
- Ответственность за контент — на владельце бота: правила Telegram и провайдера соблюдать придётся.

## Полный список команд

| Команда | Что делает |
|---|---|
| `/tone` | характер (кнопки) |
| `/persona текст` | свой характер одной фразой |
| `/name имя` | имя бота (по умолчанию Олег) — откликается на него в беседах |
| `/settings` | сводка настроек (+ кнопка Mini App в личке) |
| `/mode` | поведение в беседах: по обращению / на всё / молчать |
| `/triggers` | слова-клички, на которые бот отвечает в беседе |
| `/stopwords` | стоп-слова: бот удаляет такие сообщения (если он админ) |
| `/daily` | вечерняя сводка: on/off, time HH:MM, zone N, тест |
| `/remember` / `/memory` / `/forget` | досье: запомнить / показать / забыть |
| `/ask` / `/joke` / `/say` | прямой вопрос, шутка, сказать от имени бота |
| `/voice` | озвучить текст голосом |
| `/img` | нарисовать картинку |
| `/news` | новости по теме (Google News RSS) |
| `/yt` | пересказ YouTube-видео по субтитрам |
| `/digest` | пересказ последних сообщений беседы |
| `/quiz` / `/num` / `/dice` / `/coin` | игры |
| `/top` | рейтинг чата: баллы, активность, юмор, победы |
| `/remind` / `/reminders` | напоминания |
| `/warn` / `/mute N` / `/unmute` | модерация (админам) |
| `/ban` / `/unban` | чёрный список бота (админам) |
| `/reset` | сброс памяти и настроек чата |

## Траблшутинг

- **«BOT_TOKEN не задан»** — забыл создать `.env` (локально) или Secrets (`BOT_TOKEN`) в GitHub Actions.
- **«Модель не ответила: …»** — проверь `AI_API_KEY`/`AI_MODEL`; у бесплатного ключа Google есть лимиты в минуту —
  для 1–3 бесед хватает. Больше нагрузка → Groq.
- **Не видит сообщения в беседе** — выключи Privacy Mode у @BotFather (шаг 2).
- **Сводка/игры не работают в беседе** — это тоже Privacy Mode.
- **Реакции не считаются** — считаются автоматически, но только для сообщений за последние 2 дня (старые чистятся).
- **Бот «умер» около часа X раз в ~5 часов** — это плановый перезапуск GitHub Actions,
  посмотри вкладку Actions: сразу стартует новый прогон. Если старый завис и не стартует — нажми Run workflow вручную.
- **Сбросился характер/память** — перезапуски Actions, а база ещё не на Supabase: подключи шаг 7,
  либо восстанови `/tone` за 5 секунд.
- **Нет кнопки приложения** — не задан `PUBLIC_URL` (Secrets + Vercel из шага 7). В личном чате кнопка теперь в меню-кнопке слева от поля ввода.
- **В приложении «подпись Telegram не прошла»** — в Vercel не задан `BOT_TOKEN` или задан другой.
- **Приложение не сохраняет** — проверь `SUPABASE_URL`/`SUPABASE_SERVICE_KEY` (и в Vercel, и в Secrets), а также, что SQL-скрипт из 7.1 выполнен.
- **Уточнить, какая база у бота** — в логе Actions первой строкой: «Хранилище: Supabase…» или «…SQLite».
- **Голос не расшифровывается** — нужен ключ Groq или Gemini (проверь, кто у тебя в `AI_BASE_URL`).
- Напоминания/сводка идут по времени сервера; для сводки задай часовой пояс: `/daily zone 3`.
